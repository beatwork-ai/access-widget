אפס תלות וביצועים מעולים

        

          קוד Vanilla JS עצמאי במשקל נוצה (~35KB), ללא jQuery וללא ספריות כבדות. נטען ב-Edge CDN בלי לפגוע בציוני Google PageSpeed או LCP.
        

      


      

        
🏢

        
התאמה מלאה לכל אתרי הסוכנות

        

          סקריפט יחיד המותקן בכל אתרי הלקוחות. כל לקוח מקבל התאמה אישית של שמו, פרטי רכז הנגישות והסדרי הנגישות הפיזיים דרך תגיות Data פשוטות.
        

      

    


    
    

      

        📖 היכן להדביק את הקוד באתר הלקוח?
      

      

        

          במערכת ניהול האתרים והמשפכים (CRM):
          היכנסו אל Sites > Websites / Funnels > בחרו את האתר > Settings > הדביקו את הקוד בתיבת Body Tracking Code > שמרו.
        

        

          בוורדפרס (WordPress):
          הדביקו דרך תוסף קוד (Header and Footer Scripts) או בקובץ footer.php של התבנית, רגע לפני </body>.
        

        

          בשופיפיי (Shopify) או וובפלו (Webflow):
          הדביקו בתיבת Custom Code > Before </body>.
