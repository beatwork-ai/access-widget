⚖️

        
עמידה בחוק ובתקן ת"י 5568

        

          עונה על כל דרישות תקנות שוויון זכויות לאנשים עם מוגבלות (שירותי אינטרנט), כולל חלון מודאלי תקני להצהרת נגישות עם פרטי רכז נגישות ודיווח תקלות.
        

      


      

        
⚡

        
אפס תלות וביצועים מעולים

        

          קוד Vanilla JS עצמאי במשקל נוצה (~35KB), ללא jQuery וללא ספריות כבדות. נטען ב-Edge CDN בלי לפגוע בציוני Google PageSpeed או LCP.
        

      


      

        
🏢

        
סקלביליות לכל לקוחות הסוכנות

        

          סקריפט יחיד המותקן בכל חשבונות הלקוחות (Sub-Accounts). כל לקוח מקבל התאמה אישית מלאה של שמו והסדרי הנגישות דרך תגיות Data פשוטות.
        

      

    


    
    

      

        📖 היכן להדביק את הקוד בסאב-אקאונט?
      

      

        

          במערכת GoHighLevel (GHL):
          היכנסו אל Sites > Funnels / Websites > בחרו את האתר > Settings > הדביקו את הקוד בתיבת Body Tracking Code > שמרו.
        

        

          בוורדפרס (WordPress):
          הדביקו דרך תוסף קוד (Header and Footer Scripts) או בקובץ footer.php של התבנית, רגע לפני </body>.
        

        

          בשופיפיי (Shopify) או וובפלו (Webflow):
          הדביקו בתיבת Custom Code > Before </body>.
